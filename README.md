## About This Fork

This repository contains in-progress experiments built on top of Mihon to test advanced visual presentation features, interactive browsing widgets, and dynamic backgrounds:

* **Aurora Coverflow & 3D Flip:** Interactive Coverflow browsing mode with swipe gesture support, 3D back-cover flipping, and visual mode selector dialog.
* **Extended Library Display Modes:** Experimental Carousel Ring view, Alphabetic Rail fast-scroller, and Aurora Shelf HUD controls.
* **Top Navigation Bar:** Integrated `FoxTopSectionBar` navigation component across library, history, browse, and updates screens.
* **Dynamic Live Backgrounds:** Over 20 canvas-based procedural background shaders (Aurora Beam, Neural Flash, CRT Warp, Light Tunnel, Lightfall, Plasma Wave, Matrix terminal, and Particle simulations).
* **Display Mode Preview:** In-app settings preview widget to sample and switch between display modes in real time.

## Core Features (from Mihon)

* Local reading of manga, comics, and webtoons.
* Configurable reader with multiple viewing modes, directions, and color filters.
* Tracker support: MangaBaka, MyAnimeList, AniList, Kitsu, MangaUpdates, Shikimori, Bangumi, and Hikka.
* Categories to organize your library.
* Automatic library updates for new chapters.
* Local and cloud-compatible backups.
